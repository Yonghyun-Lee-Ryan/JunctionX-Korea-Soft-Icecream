# 대회 노트북 준비 — 맥

> [!error] 🔴 D-3. 이건 대회 전에 **반드시 한 번 실제로** 해봐야 한다
> 하네스는 윈도우(`C:\Users\cas\Documents\Obsidian Vault`)에서 만들었고, **대회는 맥으로 간다.**
> 커맨드 **12개**는 볼트 레포에 들어가 있어 `git pull`이면 따라온다. 문제는 그게 아니라 **어디서 여느냐**다.

## 🔴 가장 흔한 실패 — 커맨드가 안 보인다

Claude Code의 프로젝트 커맨드는 **현재 연 폴더의 `.claude/commands/`**만 읽는다.

| 어디서 열었나 | `/jx-*` |
| --- | --- |
| **볼트 루트** (`~/Documents/Obsidian Vault`) | ✅ 보인다 |
| 코드 레포 | ❌ **안 보인다** |
| 볼트 하위 폴더 | ❌ 안 보인다 |

**대회 중엔 창을 둘로 나눈다** — 기획은 볼트 창, 코드는 레포 창. 섞으면 커맨드가 사라진다.

> 사용자 레벨(`~/.claude/commands/`)로 옮기면 어디서든 뜨지만, 커맨드가 `30_projects/JUNCTION/...` **상대경로**를 쓰므로 볼트 밖에서는 경로가 깨진다. 옮기지 말 것.

## 대회 전 — 오늘 안에 (10분)

### 1. 볼트를 최신으로

```bash
cd ~/Documents/Obsidian\ Vault
```

```bash
git pull
```

🔴 **private 저장소다.** 인증이 안 걸려 있으면 여기서 막힌다. 막히면 `gh auth login` 또는 SSH 키를 먼저 잡는다.

### 2. 커맨드가 실제로 왔는지

```bash
ls .claude/commands/
```

**`jx-`로 시작하는 파일 12개**가 보여야 한다. 안 보이면 `git pull`이 안 된 것이다.

🔴 **이 숫자는 8/18에 `jx-skeleton`이 늘어 11→12가 됐다.** 11이 보이면 빠진 건 `jx-skeleton`이다 — 8/22 00:00에 딱 한 번 쓰는, 뼈대 범위를 가르는 커맨드다.

### 3. Claude Code를 볼트 루트에서 연다

```bash
claude
```

> [!error] 🔴 **여기서 지금 막힌다 — 대회 전에 반드시 뚫어야 한다** (2026-08-18 실측)
> 터미널에서 이걸 치면 **`Failed to authenticate: OAuth session expired and could not be refreshed`** 가 뜬다.
> 네트워크 문제가 아니다 — 온라인에서, 클린 환경에서, 데스크톱 번들 바이너리로도 **똑같이** 난다. **로그인이 만료된 것**이다.
>
> **지금 도는 유일한 경로는 Claude Desktop 앱 세션**이다(앱이 인증을 대신 쥐고 갱신한다). 터미널을 쓸 계획이면 아래를 **집 wifi에서 미리** 끝낸다:
>
> ```bash
> claude
> ```
>
> 로그인 화면이 뜨면 브라우저로 인증한다. 🔴 **재로그인에는 브라우저와 네트워크가 필요하다** — 포항에서 처음 마주치면 최악이다. 이 하네스가 현장 wifi를 안 믿는다면서 **인증이 바로 그 wifi에 걸려 있다.**
>
> **대안**: 터미널을 안 쓰고 **Claude Desktop 앱만으로 간다.** 그러면 이 항목은 무관해진다 — 대신 앱에서 볼트 폴더를 열어야 `/jx-*`가 뜬다는 조건은 그대로다.

### 4. 목록에 뜨는지 확인

`/jx` 까지 치면 12개가 떠야 한다. **하나라도 빠지면 pull이 덜 된 것이다.**

### 5. 한 번 실제로 돌린다

```
/jx-track 30_projects/JUNCTION/10_원자료/99_리허설용_가짜_트랙브리핑.md
```

리허설용 **가짜** 브리핑으로 돌려본다. 트랙 카드가 나오면 끝이다.
🔴 **현장에서 처음 돌리지 마라.** 포항 wifi로 private 레포를 클론하는 상황이 제일 나쁘다.

> [!note]- 🔴 위 함정표의 `core.autocrlf` 칸에 주의
> `git config core.autocrlf` 는 이 맥에서 **`true`로 보인다.** 그런데 local·global·system 어디에도 **설정이 없다** — 워크트리를 거쳐 읽으면 윈도우 쪽 값이 비쳐 보이는 것뿐이다.
> **실제 md는 JUNCTION 32개 전부 LF다**(2026-08-18 맥 실측). 함정표의 「LF 그대로 온다」는 결론은 맞다. 다만 **`git config` 한 줄로 판단하지 말고 파일을 직접 재라** — 볼트 `CLAUDE.md`의 「워크트리에서 잰 값을 본체로 단정하지 말 것」이 정확히 이 경우다.

### 🔴 윈도우 쪽 Obsidian을 꺼둘 것

`obsidian-git`이 **양쪽에서 5분마다 자동 커밋·푸시**한다. 대회 중 맥에서 고치는데 윈도우 Obsidian이 켜져 있으면 **충돌이 난다.** 대회 전에 윈도우 쪽을 닫아두는 게 안전하다.

### 워크트리 주의

`.claude/worktrees/`는 `.gitignore` 대상이라 맥에 안 따라온다. **본체 경로에서만 작업한다** — 원래 볼트 규칙이기도 하다.
