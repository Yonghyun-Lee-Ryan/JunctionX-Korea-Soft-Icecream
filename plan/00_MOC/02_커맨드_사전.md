## 📇 커맨드 카드 15장

### 🔴 `/jx-harvest` — 발화 채집
**하는 일**: 파트너가 입으로만 한 말에서 **브리핑에 없는 것만** 뽑는다 (차집합)
**넣는 것**: `01_트랙_브리핑_원문` + `04_현장메모` + `00_고정` 4개
**인자**: 채집 원문 경로, 또는 방금 들은 말 붙여넣기
**출력**: A(등급×신뢰) · B(새 어휘) · C(되먹일 곳) · D(다시 물을 것)
**절대 금지**: 인용을 보태기 · 파편 복원 · 화자 추측
> **하네스에서 유일하게 바깥에서 새 입력을 들여오는 자리.** 이것만이 진짜 차별화다 → [[10_발화채집]]

### `/jx-track` — 트랙 해부
**하는 일**: 파트너가 **진짜 원하는 것**을 뽑는다. 아이디어는 안 낸다
**넣는 것**: `00_고정` 4개 + 트랙 브리핑
**인자**: 브리핑 경로. 여러 트랙이면 공백 구분. 🔴 **생략하면 [[01_트랙_브리핑_원문]]을 읽는다 — 08-21 20:00에 그 파일이 채워졌으므로 지금은 인자 없이 도는 게 기본**
**병렬**: 🔴 **트랙마다 서브에이전트 1개.** 한 에이전트에 여러 트랙을 주면 비교를 시작한다 — 비교는 사람이 한다
🔴 **08-21 기준 병렬 폭 = 1**(원문이 Upstage 1건). 폭이 1이어도 이 커맨드를 건너뛰지 마라 — 하는 일은 「트랙 비교」가 아니라 「파트너가 진짜 원하는 것 추출」이고, 트랙이 하나여도 그 일은 그대로 필요하다
**출력 끝**: D-2 판정 규칙을 **탈락/순위 나눠서** 채운다 → [[06_트랙해부]]

### `/jx-common` — 평범한 답 선점
**하는 일**: **다른 팀이 낼 답**을 먼저 뽑아 금지목록에 넣는다
**넣는 것**: 트랙 브리핑 + `03_금지목록`  🔴 **`02_팀과_제약`은 넣지 마라** (우리 제약을 넣으면 예측이 우리 쪽으로 끌린다)
**타이밍**: `/jx-track`과 **동시**. 서로 의존 안 하니 추가 시간 0
**놓치면 안 되는 것**: **C(그래도 맞을 수 있는 것)** — A를 전부 금지하면 가장 옳은 답까지 버린다 → [[11_평범한답]]
🔴 **08-21 — 이번 브리핑은 평범한 답을 브리핑이 직접 적어줬다.** Background의 네 예시(`scholarship applications · housing lease contracts · part-time employment contracts · club expense receipts`)는 **트랙 발표를 본 팀이 다 읽은 줄**이다. 출력 A에 이 넷이 없으면 **손으로 넣는다.** 단 C를 먼저 확인 — 넷을 전부 금지하면 가장 옳은 답까지 버린다

### `/jx-diverge` — 아이디어 확산
**하는 일**: 각도 4개로 **구조적으로 다른** 후보를 만든다
**넣는 것**: `00_고정` 4개 + **트랙 브리핑(필수)** ✅ **08-21 확보 — 인자 없이 [[01_트랙_브리핑_원문]]을 읽는다** + 트랙해부 결과
**인자**: 각도 번호 1–4. 생략하면 4개 병렬
**병렬**: 🔴 **각도마다 1개.** 한 에이전트에 4각도를 주면 이 역할의 존재 이유가 사라진다
🟢 **트랙이 1개로 줄어도 각도 4개는 안 줄인다.** 각도는 트랙 수가 아니라 출발점의 수다
**순서**: `/jx-common` **다음에** 돌린다. 금지목록이 먼저 차야 그 바깥에서 나온다 → [[07_아이디어확산]]

### `/jx-skeptic` — 회의론자
**하는 일**: 후보를 **각각 독립적으로** 죽인다. 장점 한 줄도 금지
**넣는 것**: `00_고정` 4개 + `20_산출물`
**인자**: 후보 설명 또는 파일 경로. 여러 개면 공백 구분
**병렬**: 🔴 **후보마다 1개.** 순차로 하면 앞의 것에 앵커링된다
**쓰고 나서**: 버린 건 **즉시** `03_금지목록`으로 → [[03_회의론자]]

### `/jx-questions` — 질문 생성

**넣는 것**: `00_고정` 4개 + `20_산출물` + **트랙 브리핑** ✅ **발표 후다 — 필수.** [[01_트랙_브리핑_원문]]
**출력에서 볼 것**: **B(사람에게 물을 것)를 그대로 들고 나간다** — 워크숍 1시간 + 피드백 9시간이 시간표에 박혀 있다 → [[05_질문생성]]
🔴 **08-21 시점에 덱이 답을 안 주는 것 셋**(피드백 9시간 창구에 들고 갈 후보): ① **Upstage Studio를 「처음 쓰는 기술」로 세야 하나** — 노코드(`no code required`)라 판단이 갈리고 하드룰 4에 직결된다 → [[02_팀과_제약]] ② **크레딧 $50/인의 실제 소진 속도** — 개발 중 반복 호출 ③ **덱에 없는 제품**(Solar Pro 4·AI Space 등)이 지금도 있는지. 🔴 **덱에 없다 = 없다가 아니다.** 단정하지 말고 물어본다. 질문지 본체는 [[05_워크숍_질문지]]

**읽는 법**: 🔴 **점수는 버리고 감점 사유만.** "심사장에서 던질 질문 5개"가 제일 값어치 있다
