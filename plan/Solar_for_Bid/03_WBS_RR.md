### 🔴 왜 「필드」가 아니라 「봉투」인가 — 04:00 동결의 내용이 바뀌었다

프리플라이트(08:00)가 동결(04:00)보다 **뒤에** 있다. 지금 캔버스 0개·실행 0회이고, **200쪽 HWP에서 Extract가 무엇을 어떤 모양으로 뱉는지 아무도 본 적이 없다.** 게다가 장문 F1이 41.3/63.2라 **값이 안 나오는 필드가 반드시 생긴다.**

필드 이름으로 계약하면 두 갈래뿐이다 — (a) 동결이 미뤄져 프론트·백이 대기하거나 (b) 추측으로 얼렸다가 08:00에 뒤집혀 **화면③ 탭4와 xlsx 빌더가 동시에 재작업**(6~8ph, 여유의 대부분).

**그래서 봉투만 얼린다** → `04_계약/factsheet.envelope.json`

```
{ caseId, status, progress[],
  verdict:{ badge:"go|no-go|conditional", headline, reasons:[{text,page,docId,confidence}] },
  tabs:[{ id, title, columns:[str], rows:[[str]], warnings:[str], summary }],
  downloads:[{ id, label, url }], meta:{ cached, agentId, configVersion, attachments[] } }
```

🟢 **프론트는 `columns`/`rows`를 범용 표로 렌더한다.** Extract가 뭘 뱉든, 탭이 늘든 줄든, 열이 바뀌든 **화면 코드가 안 바뀐다.** 필드 이름·개수는 전부 백엔드 안쪽 사정이 된다.
🟢 그리고 **`04_계약/factsheet.demo.json`(손으로 채운 가짜 1건)을 이미 커밋했다** — 이용현이 백엔드를 기다리지 않고 화면③까지 완주할 수 있다.
