## 한 줄 그림

```
[회사 서류 묶음] ─S1─▶ Parse→Classify→Extract → 「회사 카드」 (1회·캐시)
   ─S2─▶ 조달청 OpenAPI 목록 → 메타 필터 → 후보 N건 (Parse 0원)
   ─S3─▶ 후보만 G2B 첨부 수집 (fileSeq 1..N · 422=끝 · 키 불필요)
          → Parse(HWP 직접) → Classify 9갈래(Split ON) → Extract 8스키마
   ─S4─▶ judge_eligibility: 제외 / 추천 → 「127건 중 3건」 → 🚪 응찰
   ─S5~6─▶ 조견표(웹 체크리스트) → WBS → 임계경로 → M/M 예상 원가(추천)
   ─S7~8─▶ (Should) 질의서 초안 · 제출 체크리스트 검사 + 보완요청
   ─S9─▶ ⛔ 투찰은 사람
```
