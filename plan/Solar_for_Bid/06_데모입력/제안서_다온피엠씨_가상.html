Ⅰ. 제안개요

1. 제안목적 및 배경

본 제안은 중소 제조기업의 AX 성숙도를 진단하고 그 결과를 컨설팅으로 잇는 통합 웹 서비스를 개발하기 위한 것입니다. 당사는 공공 정보화 사업 8건의 수행 경험을 바탕으로 KISTI가 연구해 온 AX 성숙도 진단 툴킷을 실제로 동작하는 서비스로 구현합니다.

2. 제안의 범위 및 전제조건

제안 범위는 진단 프레임워크 검토 자문, 하이브리드 RAG 지식베이스 및 벡터 DB 구축, 자동화 진단-컨설팅 엔진 개발, 컨설팅 콘텐츠 생성, 웹 서비스 프로토타입 개발과 PoC 실증, 관리자 기능 및 운영 문서화입니다. 진단 영역별 세부 평가항목은 KISTI가 제공하는 기준을 그대로 따릅니다.

3. 제안의 특성 및 장점

당사는 진단 결과와 컨설팅 콘텐츠 사이의 연결 규칙을 코드가 아니라 데이터로 관리합니다. 평가항목이 바뀌어도 엔진을 다시 만들지 않고 규칙 테이블만 교체하면 됩니다.

Ⅲ. 전략 및 방법론

1. 사업 이해도

본 사업의 핵심은 「진단이 컨설팅으로 이어지는가」입니다. 진단 점수만 내는 도구는 이미 많으나, 점수에서 실행 가능한 데이터 준비 전략과 인증 절차로 이어지는 경로는 비어 있습니다.

2. 추진 전략

착수 4주 내 진단 프레임워크 검토를 마치고, 이후 8주 동안 엔진과 웹 서비스를 병렬로 개발하여 PoC 실증에 2주를 확보합니다.

3. 적용 기술

하이브리드 RAG는 키워드 검색과 벡터 검색을 함께 사용하는 구조로 구현합니다. 향후 요구가 있을 경우 외부 LLM 서비스와의 연계도 가능합니다.

Ⅳ. 기술 및 기능

1. 진단 기능 (SFR-001 ~ SFR-005)

SFR-001 도메인 모드 선택 기능 — 서비스 시작 화면에 「범용AX」와 「피지컬AX」 2종 모드 선택 구분을 제공하고, 선택한 모드를 세션 전반에 유지하여 이후 진단·컨설팅 전 단계에 일괄 적용합니다. 모드를 선택하지 않으면 다음 단계 진행을 차단하고 안내 메시지를 표시합니다.

SFR-002 진단그룹 자동 분류 — AX 기본역량 파악 초기 질의를 제공하고, 응답값을 분석해 A/B/C 그룹으로 자동 매칭하는 로직을 구현합니다. 그룹별로 진단 경로를 분기합니다.

SFR-003 AX 성숙도 진단 기능 — KISTI가 제공하는 진단 영역 기준에 따라 멀티턴 질의응답 형식의 진단을 수행합니다.

SFR-004 진단 채점 로직 — 영역별 가중치와 환산 규칙을 규칙 테이블로 분리하여 구현하고, 채점 근거를 응답 단위로 보존합니다.

SFR-005 진단 결과 대시보드 — 영역별 점수, 그룹 내 상대 위치, 취약 영역을 한 화면에 제공합니다.

2. 컨설팅 기능 (SFR-006 ~ SFR-007)

SFR-006 AX 전환 전략 가이드 자동 생성 — 진단 결과에 대응하는 전환 전략 가이드를 RAG 기반으로 생성하고 생성 근거 문단을 함께 제시합니다.

SFR-007 맞춤형 데이터 전략 컨설팅 — 기업의 데이터 보유 현황 응답을 기준으로 데이터 준비 단계별 과제를 제시합니다.

3. 리포트 및 사용자 관리 (SFR-009 ~ SFR-010)

SFR-009 통합 PDF 리포트 자동 생성 — 진단 결과와 컨설팅 콘텐츠를 하나의 PDF 리포트로 자동 생성합니다.

SFR-010 사용자/관리자 기능 분리 — 사용자 화면과 관리자 화면을 분리하고 권한 기반으로 접근을 통제합니다.

4. 인터페이스 (INR-001 ~ INR-002)

INR-001 웹 표준화 인터페이스 — 웹 표준을 준수하여 구현합니다.

INR-002 반응형 웹 UI — 데스크톱과 모바일 화면 폭에 대응하는 반응형 UI를 제공합니다.
