# 시장과 BM

> [!error] 🔴 이 문서는 **기업 관점이 실제로 지켜졌는지 재는 자리**다
> 이 하네스가 푸는 문제의 소유자는 개인 사용자가 아니라 **Challenge Partner 회사**다. 그 원칙이 지켜졌는지는 [[01_문제정의]]로는 안 보인다 — 거기는 문제가 진짜인지만 묻는다.
> **A칸을 못 채우면 우리는 기업의 문제가 아니라 우리가 상상한 문제를 풀고 있는 것이다.** 그때는 기획으로 돌아간다.

**재료**: [[13_기업해부]] → A·B / [[14_수익논리]] → C·D·E
**언제**: 8/22 낮(미션 2 전)에 처음 채우고, 8/23 발표 준비 때 갱신
**분량**: 이 문서 전체가 발표에서 **세 문장**으로 나간다. 길게 쓰되 나갈 때는 세 문장이다

## A. 이 기업이 왜 이걸 원하는가

> 🔴 **이 칸이 이 문서의 뿌리다.** 나머지 넷은 여기서 자란다.

이 과제를 풀면 파트너 회사에 무엇이 생기는가. **넷 중 하나로 좁힌다.**

| | 해당 | 근거 (브리핑 인용 · 담당자 발언 · 공개 자료) |
| --- | :---: | --- |
| 매출이 는다 | | |
| 원가가 준다 | | |
| 리스크가 준다 | | |
| 아직 모르는 것을 알게 된다 | | |

**한 문장으로**: `[채우기]`

```
[파트너 회사]는 [무엇] 때문에 [무엇]을 [얼마나] 쓰고 있고, 이 과제를 풀면 그게 [어떻게] 바뀐다.
```

⚠️ **넷 다 체크되면 아무것도 안 고른 것이다.** 하나로 안 좁혀지면 [[13_기업해부]]를 다시 돌린다.

| --- | --- | --- | --- | --- | --- |
| | | | | | |
| | | | | | |

**등급** 🔴새 사실 / 🔴문서 뒤집기 / ⚠️문서와 모순 / 🔵회피 · **신뢰** ✅확실 / ⚠️재확인 · **누가** 담·엔·멘·스·팀·우 (모르면 `?`)

🔴 **맨 끝 칸이 이 표의 존재 이유다.** *"사용자가 불편해한다"*는 여기 들어갈 수 없다. **회사의 돈·시간·리스크에 걸린 근거**만 들어간다.

## C. 수익 논리

**단위 문장** — 이걸 먼저 채운다. 단위 없는 절감은 절감이 아니다.

```
이 제품은 [무엇] 한 건당 [무엇]을 [얼마] 줄인다.
```

`[채우기]`

| 항목 | 값 | 출처 | 계산식 |
| --- | --- | --- | --- |
| 돈을 내는 주체 (어느 예산) | | | — |
| 한 건당 현재 비용 | | | |
| 한 건당 우리 방식 비용 (**추론 비용 포함**) | | | |
| 차액 | | | |
| 월 건수 | | | |

**출처**: 파트너가 말했다 / 브리핑에 있다 / 공개 자료 / 우리 추정(계산식 필수) 중 하나를 밝힌다.
🔴 **한 줄이라도 출처가 없으면 그 줄을 비운다.** 채우지 말고 비운 채로 둔다.
🔴 **차액이 음수여도 그대로 쓴다.** 음수면 이건 원가 절감 제품이 아니라는 발견이고, 그러면 단위 문장을 다시 쓴다.

## D. 규모 — 좁은 것부터

> [!warning] 🔴 [[03_금지목록]]과의 관계 — 금지되는 것은 *추정*이 아니라 **지어내기**다
> 금지목록은 "사용자 수·시장 규모 추정치를 지어내기"를 상시 금지한다. 이 칸은 그 규칙을 **깨지 않는다.**
> **계산식과 각 입력값의 출처를 보이는 추정만 쓴다. 입력값 중 하나라도 출처가 없으면 그 숫자 전체를 버린다** — 절반만 출처가 있는 계산은 출처 없는 계산이다.

| 단계 | 값 | 계산식 | 입력값 출처 |
| --- | --- | --- | --- |
| ① 지금 당장 세어지는 것 (고객사·센터·팀 수) | | | |
| ② 그중 이 문제를 겪는 몫 | | | |
| ③ 더 넓은 시장 | | | |

🔴 **순서를 뒤집지 마라.** ③부터 쓰면 그 숫자에 맞춰 ①②를 지어내게 된다.
🔴 **근거가 끊기는 단계에서 멈추고 「여기서 끊겼다」고 적는다.** 이어 붙이지 마라.

**①만 채워도 충분한 경우가 많다.** *"파트너 고객사 14곳, 각 연 N건"*은 검산되고 반박이 안 된다. ③은 심사에서 반박하기 가장 쉬운 자리다.
